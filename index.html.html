📖 使用说明

普通队员：只能使用「借物资」「我的登记」两个页面，借用时按分类挑选物品，不需要填归还时间；归还时在自己的登记里点「归还」，自动记录归还日期。

后勤部成员：在队员页底部点「后勤部成员管理入口」，输入管理密码（初始 123456，可在数据页修改）解锁，可查看并修改全部借还登记、管理物资状态和存放位置、维护换旗日历。

借出联动：有人借用后，对应物资在选物页和管理端物资页都会实时显示紫色「借出」标记，可借数量随之减少；点「归还」后自动恢复。 物资越来越多怎么办？管理端在「物资」页点「🗂️ 门类」可以新增门类（如手套、领带、旗子），再在每个门类里「➕ 添加物品」；新门类会自动出现在队员的借物页，借出联动同样生效。

人员核对：队员首次打开需登记姓名（管理员可在「数据 → 队员名单」预置名单），之后借用自动带出姓名，「我的登记」只显示自己的记录，可随时在页面底部「切换身份」。

☁️ 多设备实时同步：管理员在「数据 → 云同步」设置一次 LeanCloud 或 Supabase 免费后端，生成「同步码」发到群里；每人粘贴一次即可。此后任何登记/修改约 2 秒内自动同步到所有设备，无需再手动上报。

怎么发给大家？把这个 html 文件发到微信群 / QQ 群，手机点击后用浏览器打开；iPhone 用 Safari 打开后「分享 → 添加到主屏幕」就像一个 App。
